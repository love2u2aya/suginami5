# ボーイスカウト杉並5団 告知プロジェクト

## 概要

新規入団者の獲得を目的とした、告知・広報活動の設計ドキュメント集。

対象：ビーバースカウト（年長〜小1）、カブスカウト（小2〜小5）

## ドキュメント構成

```
strategy/
  overview.md        チャネル全体の役割設計
  instagram.md       Instagram戦略
  flyer.md           チラシ戦略
  poster.md          ポスター戦略
  wordofmouth.md     口コミ戦略
  event_to_daily.md  大規模イベント→日常活動への転換

line/
  strategy.md        LINE公式アカウント戦略
  welcome.md         友達追加直後の自動応答設計
  monthly_plan.md    月次配信プラン（6月サンプル）

data/
  survey_analysis.md 2026/5/10イベント アンケート分析（n=23）

content/
  line_templates.md  LINEメッセージ文面テンプレート
```

## チャネル全体の情報の流れ

```
チラシ・ポスター・名刺カード（QRコード）
        ↓
    LINE公式 ←→ Instagram
        ↓
    HP（体験ページ・活動報告・FAQ）
        ↓
    体験申込フォーム（Googleフォーム）
        ↓
        入団
```
