## PART B｜Googleフォーム詳細設定ガイド

### フォームの作成手順

1. https://forms.google.com/ にアクセス
2. 「+」ボタンで新規作成
3. タイトルとフォームの説明を入力
4. 質問を追加していく
5. 「送信」ボタン → リンクをコピー → LINEのキーワード応答に貼り付け

### 回答通知の設定（重要）

「回答」タブ → 右上のスプレッドシートアイコン → 「新しいスプレッドシートを作成」
→ Googleスプレッドシートと連携して管理

### フォームの「確認メッセージ」設定（コピペ用）

**設定場所：** フォーム設定 → プレゼンテーション → 確認メッセージ

```
お申し込みありがとうございます！

24時間以内に、ご記入のLINEまたはメールへ
担当者からご連絡いたします。

当日は私服・手ぶらでお越しください。
なにかご不明な点はLINEへご連絡ください。
```

## PART H｜引き継ぎ・担当者交代時のチェックリスト

LINE担当者が変わる際に確認する項目：

### アカウント情報の引き継ぎ

- [ ] LINE Official Account Manager のログイン情報
- [ ] Lステップのログイン情報
- [ ] Googleフォームの編集権限の追加
- [ ] Googleスプレッドシート（申込管理）の共有
- [ ] 月次レポートの引き継ぎ

### 設定内容の確認

- [ ] タグ定義の説明
- [ ] シナリオの内容と流れ
- [ ] キーワード応答の現在の設定
- [ ] 〔URL〕部分に入っている実際のリンクの確認
