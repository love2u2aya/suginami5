# LINE 友達追加直後の自動応答設計

## 流れ

```
友達追加
  ↓ 即時（自動）
あいさつメッセージ（1通目）
  ↓
リッチメニューが表示される
  ↓
相手が返信 or ボタンをタップ
  ↓ 24時間以内（手動）
担当者が個別返信
```

## あいさつメッセージ

```
ボーイスカウト杉並5団へようこそ！

年長〜小学5年生を対象に、
毎月2回ほど野外活動をしています。

まずは見学だけでも大歓迎です。
入団を決めなくても全然OKです。

---
気になることがあれば、
このトークに直接メッセージをください。
担当者が直接お答えします。

下のメニューもご覧ください👇
```

**設計のポイント：**
- 3秒で読める量に収める
- 「入団しなくてもOK」を最初に明言する
- 最後に返信を促す
- 堅くなりすぎない口調
