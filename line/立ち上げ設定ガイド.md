# LINE公式アカウント 立ち上げ設定ガイド
## ボーイスカウト杉並5団｜コピペで使える完全手順書

---

## STEP 1｜LINE Official Account Manager でアカウント作成

1. https://manager.line.biz/ にアクセス
2. 「作成する」→ LINEアカウントでログイン
3. アカウント情報を入力：

| 項目 | 入力値 |
|---|---|
| アカウント名 | ボーイスカウト杉並5団 |
| 業種 | 教育・学習 → その他 |
| メールアドレス | 団のGmailアドレス |

4. 「確認する」→「作成する」

---

## STEP 2｜プロフィール設定

**設定場所：** アカウント設定 → 基本設定

### アイコン
- 1:1の正方形（推奨640×640px）
- 団のロゴ、または緑の背景にスカウト活動の写真

### ステータスメッセージ（コピペ用）
```

```

## STEP 3｜応答設定

**設定場所：** 応答設定

| 項目 | 設定値 | 理由 |
|---|---|---|
| 応答モード | チャット | 担当者が手動返信できる |
| あいさつメッセージ | オフ | Lステップ側で管理 |
| 自動応答メッセージ | オフ | Lステップ側で管理 |
| Webhook | オン | Lステップ連携に必須 |

---

## STEP 4｜Lステップ連携

1. https://lstep.app/ にアクセス → 新規登録
2. 「LINE連携」をクリック → 公式アカウントと連携
3. LINE Official Account Manager → 「Webhook設定」→ LステップのWebhook URLを入力
4. Lステップ管理画面 → 「チャンネル設定」で「連携済み」を確認

---

**設定場所：** Lステップ → 友だち管理 → タグ管理 → 新規タグ作成

以下のタグをすべて作成してください：

**年代タグ（どれか1つ付与）**
- `ビーバー隊` （年長〜小1）
- `カブ隊` （小2〜5）
- `ボーイ隊` （中学生）
- `ベンチャー隊` （高校生）

**親の属性タグ（どれか1つ付与）**
- `パパ`
- `ママ`
- `パパママ両方`

**状況タグ（該当時に付与）**
- `体験済み`
- `入団済み`
- `資料請求済み`

## STEP 10｜リッチメニュー設定（Lステップ）

**設定場所：** Lステップ → リッチメニュー → 新規作成

### レイアウト：2行×3列（6ボタン）

```
┌──────────┬──────────┬──────────┐
│  体験会に  │ 活動の様子 │よくある質問│
│ 申し込む  │  を見る   │（費用など）│
├──────────┼──────────┼──────────┤
│担当者に   │  活動日程  │  入団まで  │
│話しかける │  を確認   │  の流れ   │
└──────────┴──────────┴──────────┘
```

### 各ボタン設定

| ボタン | アクション | 設定値 |
|---|---|---|
| 体験会に申し込む | URL | Googleフォームのリンク |
| 活動の様子を見る | URL | InstagramのプロフィールURL |
| よくある質問（費用など） | URL | HP FAQページURL |
| 担当者に話しかける | テキスト送信 | 「担当者に相談したい」 |
| 活動日程を確認 | URL | HP活動カレンダーURL |
| 入団までの流れ | URL | HP入団ページURL |

### 画像仕様
- サイズ：2500×1686px
- 推奨ツール：Canva（「LINE リッチメニュー」で検索）
- 背景色：スカウトグリーン（#2E7D32）基調

## PART 4｜月次運用チェックリスト

### 毎月1日にやること

- [ ] 月の活動日程を確定し、全キーワード応答内の「次回の活動日」を更新
- [ ] 活動カレンダーページ（HP）を更新
- [ ] 先月の配信通数を確認（200通の残枠を把握）
- [ ] 新規登録者のタグ付けに漏れがないか確認
- [ ] 体験会参加者への「体験済み」タグ付与
- [ ] 入団者への「入団済み」タグ付与・配信除外設定

### 毎月の配信スケジュール（目安）

| 日程 | 内容 | 対象 | 通数目安 |
|---|---|---|---|
| 1日 | 月初めのごあいさつ＋活動予定 | 全員 | 20通 |
| 活動前3日 | 活動リマインダー | 全員 | 20通 |
| 活動翌日 | 活動レポート（写真付き） | 全員 | 20通 |
| 月中旬 | セグメント別コンテンツ | 各セグメント | 計40通 |
| 月末 | 翌月の予定案内 | 全員 | 20通 |
| 随時 | 体験会案内（体験未経験者のみ） | セグメント | 40通 |

**合計目安：160通 / 200通上限**
