## パパ向けコンテンツ（月1〜2回）

### パパ向け文例① 「スカウトが育てるリーダーシップ」

**テーマ：** 論理的な根拠を示し、投資価値を伝える
**送る写真：** 子どもたちが話し合い・役割分担をしているシーン（全体・引き画）

```
【パパ向け】スカウトが育てる力

子どもをスカウトに入れる親御さんから、
よく聞く言葉があります。

「うちの子、急に『自分でやる』って言い出した」

スカウトでは、大人がやり方を教えても
「答え」は教えません。

ロープの結び方は教えます。
でも「どの結び方を使うか」は
子ども自身が考えます。

地図の読み方は教えます。
でも「どのルートで行くか」は
子ども自身が選びます。

この繰り返しが、
「自分で考えて、動く力」を育てます。

学校では教えてもらいにくい、
でも大人になって一番大切になる力です。

──────────────
📅 次回の活動：〔○月○日（○）〕
見学はいつでも大歓迎です。
気になることはこのLINEに返信してください。
```

### パパ向け文例② 「失敗を経験させる意味」

**テーマ：** 失敗体験の教育的価値。過保護な環境への問題提起
**送る写真：** 子どもが一人で何かに挑戦している様子（表情が見えるもの）

```
【パパ向け】失敗させることの意味

先日の活動で、こんなことがありました。

火おこしに挑戦した小3の子が、
1時間以上かかってもできなかった。

大人のリーダーは手を出しません。
「もう少しだよ」「ここを変えてみて」
声をかけながら見守るだけです。

結局、その日はできませんでした。

でも次の活動で、
その子は最初に火をおこしました。

失敗した理由を、自分で考えていたからです。

「失敗していい環境」は、
今の時代、意外と少ない。

スカウトでは、
失敗することも活動のうちです。

──────────────
📅 次回の活動：〔○月○日（○）〕
見学はいつでもどうぞ。
```

### パパ向け文例③ 「スカウトの費用対効果」

**テーマ：** 習い事の費用比較。合理的な判断を促す
**送る写真：** 野外炊事・キャンプなど「非日常感」のある活動シーン

```
【パパ向け】スカウトのコストを整理する

月会費：〔○〕円前後
入団金：〔○〕円（初回のみ）
年間キャンプ：〔○〕円前後（2泊3日）

他の習い事と比べると──

水泳・英語・学習塾：月1〜3万円
スカウト：月2,000〜3,000円前後

コストが低い理由は、
リーダーが全員ボランティアだからです。

子どもに何かを学ばせたいと思ったとき、
スカウトは選択肢として
かなり費用対効果が高いと思っています。

夏のキャンプも、一般のキャンプ場に
家族で行くより安いケースが多いです。

──────────────
費用の詳細はご質問ください。
このLINEに「費用について」と返信するか、
下のボタンからどうぞ。

  ［ 費用の詳細を聞く ］
```

## ママ向けコンテンツ（月1〜2回）

### ママ向け文例① 「人見知りだった子の話」

**テーマ：** 入団前の不安を解消。変化のエピソードで共感を呼ぶ
**送る写真：** 子どもたちが輪になって笑っているシーン、または新しい友達と並んでいるシーン

```
【ほっこりエピソード】

入団前、お母さんからこんな相談を受けました。

「うちの子、すごく人見知りなんですが、
 大丈夫でしょうか？」

入団して3ヶ月後。

その子は活動が終わると
「次いつ？」と聞くようになりました。

知らない子に自分から話しかけるようになりました。

名前を覚えるのも早くて、
今では年下の子の面倒もよく見ています。

スカウトの活動は、特別なことをしているわけじゃないんです。

一緒に何かをやる。
うまくいかなかったら笑う。
できたら一緒に喜ぶ。

その繰り返しの中で、
気づいたら友達になっている。

そういう場所です。

──────────────
見学だけでも大歓迎です。
「行ってみようかな」と思ったら
このLINEに返信してください😊
```

## 写真選びの基準

| 優先順位 | どんな写真 | 理由 |
|---|---|---|
| ◎ 最優先 | 子どもが「できた！」という表情をしているアップ | 感情が伝わる・共感される |
| ◎ 最優先 | 夢中になって何かに取り組んでいる横顔 | 集中・本気感が伝わる |
| ○ 優先 | 複数の子どもが協力しているシーン | コミュニティ感が伝わる |
| ○ 優先 | 自然・緑の中での活動シーン | アウトドア感・非日常感 |
| △ 補助 | 活動の道具・成果物（作ったもの等）| 活動内容の説明に |
| × 使わない | ピンボケ・暗い写真 | 信頼感を損なう |
| × 使わない | 子どもが泣いている・嫌そうな表情 | 誤解を生む |

### 顔の掲載ルール

- 顔が映る写真：その子の保護者に送信前に確認を取る
- 許可リストを管理表で管理する（名前・許可日・確認方法）
- 不明な場合：後ろ姿・遠景を使う
