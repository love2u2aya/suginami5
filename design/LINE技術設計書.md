# LINE公式アカウント 技術設計書

対象読者：運用担当者（IT知識あり）
目的：本ドキュメントのみで設定・運用が完結できること

---

## 1. システム構成

```
[ユーザー]
    ↓ 友達追加
[LINE公式アカウント]
    ↓ Webhook
[Lステップ]
    ├─ シナリオ管理（自動応答・タグ付け・ステップ配信）
    ├─ セグメント管理（ビーバー/カブ × パパ/ママ）
    └─ 一斉配信（セグメント絞り込み）
```

### 使用サービス

| サービス | 用途 | プラン | 費用 |
|---|---|---|---|
| LINE公式アカウント | 配信本体 | 無料（200通/月） | 無料 |
| Lステップ | 自動化・セグメント管理 | 無料（〜50人）| 無料 |
| Googleフォーム | 体験申込受付 | 無料 | 無料 |
| Canva | 画像・動画制作 | 無料 | 無料 |

---

## 2. タグ定義（Lステップで設定）

| タグ名 | 付与条件 | 用途 |
|---|---|---|
| `ビーバー` | 「年長・小1」ボタンをタップ | ビーバー向け配信対象 |
| `カブ` | 「小2〜小5」ボタンをタップ | カブ向け配信対象 |
| `パパ` | 「パパです」ボタンをタップ | パパ向けコンテンツ対象 |
| `ママ` | 「ママです」ボタンをタップ | ママ向けコンテンツ対象 |
| `両方` | 「どちらも見ます」ボタンをタップ | 両方のコンテンツ対象 |
| `体験済み` | 体験会参加後に手動付与 | 入団フォロー対象 |
| `入団` | 入団手続き完了後に手動付与 | 既存団員（配信除外） |

## 3. ユーザー到達フロー（シナリオ設計）

### Step 0：友達追加トリガー
- **Lステップ設定箇所**：シナリオ → 新規作成 → トリガー：「友だち追加時」
- **即時実行**：あいさつメッセージ（下記）を送信

---

### Step 1：あいさつメッセージ（即時・自動）

**メッセージ種別**：テキスト＋ボタン（Lステップ：ボタンテンプレート）

```
【コピペ用テキスト】
ボーイスカウト杉並5団へようこそ！

年長〜小学5年生を対象に、
毎月2回ほど野外活動をしています。

まずは見学だけでも大歓迎です。
入団を決めなくても全然OKです。

お子さんに合わせた活動紹介動画を
プレゼントします🎁

お子さんは今、何年生ですか？
```

**ボタン設定（Lステップ：ポストバックボタン）：**

| ボタンラベル | アクション | タグ付与 |
|---|---|---|
| 年長・小学1年生（ビーバー隊） | postback: `age_beaver` | `ビーバー` を付与 |
| 小学2〜5年生（カブ隊） | postback: `age_cub` | `カブ` を付与 |

**Lステップ設定メモ：**
- ボタン数：2
- ボタン種別：ポストバック（タップ時にタグ付与＋次アクション実行）
- この送信は200通カウント**外**

---

楽しんでいる様子をご覧ください。

気になることはいつでも返信してください😊
```

#### カブ向け

```
【コピペ用テキスト】
ありがとうございます！

こちらがカブ隊（小2〜小5）の
活動紹介動画です🎬

▼ 動画はこちら
[動画ファイルをここに添付]

子どもたちが自分で考えて
動いている様子をご覧ください。

**Lステップ設定メモ：**

### Step 3：パパ・ママ確認（Step 2の3日後・自動）

**Lステップ設定箇所**：シナリオ → Step 2の次のステップ → 待機：3日

```
【コピペ用テキスト】
先日は動画をご覧いただきありがとうございました。

よりお役に立てる情報をお届けするために、
一つだけ教えてください。

LINEをご覧になっているのはどなたですか？
```

**ボタン設定：**

| ボタンラベル | アクション | タグ付与 |
|---|---|---|
| パパです | postback: `gender_papa` | `パパ` を付与 |
| ママです | postback: `gender_mama` | `ママ` を付与 |
| 両方で見ています | postback: `gender_both` | `両方` を付与 |

**Lステップ設定メモ：**
- 送信タイミング：Step 2から72時間後
- この送信は200通カウント**対象**（注意）
- ※無料枠20人の場合：20通消費

## 4. 一斉配信（活動レポート等）の設定

### 配信手順（毎回）

1. Lステップ管理画面 → 「配信」→「新規配信」
2. 配信対象：タグで絞り込み（例：`カブ` のみ）
3. 配信日時：翌日以降の8:00〜21:00の間で予約
4. 内容を入力 → プレビュー確認 → 予約送信

### 配信可能時間帯

**推奨送信時間：**
- 朝：8:00〜9:00（通勤・登校前にチェックする層）
- 昼：12:00〜13:00（昼休み）
- 夜：20:00〜21:00（夕食後・就寝前）

**Lステップ設定箇所**：「自動応答」→「キーワード応答」

## 8. 200通カウントの管理

| メッセージ種別 | カウント |
|---|---|
| 友達追加あいさつ | **対象外** |
| ポストバック（ボタン反応）| **対象外** |
| シナリオ配信（自動ステップ送信）| **対象** |
| 一斉配信 | **対象** |
| 個別トークへの返信 | **対象外** |

**月間カウント試算（登録者20名の場合）：**

| 内容 | 通数 |
|---|---|
| Step 3（パパ/ママ確認）× 20人 | 20通 |
| Step 4（2本目動画）× 20人 | 20通 |
| Step 5（3本目動画）× 20人 | 20通 |
| 活動レポート × 4回 × 20人 | 80通 |
| 体験会告知 × 2回 × 20人 | 40通 |
| **合計** | **180通** |

→ 無料枠（200通）で運用可能。余裕は20通。
