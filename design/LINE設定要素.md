# LINE公式アカウント 設定要素詳細

設定画面URL：https://manager.line.biz/
Lステップ管理URL：https://lstep.app/

---

## 1. アカウントプロフィール設定

**設定箇所：** LINE Official Account Manager → アカウント設定

| 項目 | 設定値 |
|---|---|
| アカウント名 | `ボーイスカウト杉並5団` |
| アカウントID | 任意（例：`@scouts_suginami5`）※英数字のみ |
| プロフィール画像 | 団のロゴ or スカウトの制服を着た子の後ろ姿（1:1正方形・推奨640×640px）|
| 背景画像 | 活動中の横長写真（推奨1080×878px）|
| ステータスメッセージ | `年長〜小5 自然体験・野外活動 📍杉並区` |
| 説明文（プロフィールページ） | 以下を設定 |

**説明文（コピペ用）：**
```
🌲 ボーイスカウト杉並5団

年長〜小学5年生を対象に、
毎月2回ほど野外活動をしています。

キャンプ・ロープワーク・料理・
自然探検など、本物の体験を通じて
「自分で考えて動く力」を育てます。

見学・体験はいつでも大歓迎。
入団しなくてもOKです。

お気軽にメッセージをどうぞ。
担当者が直接お答えします。
```

## 2. 応答設定

**設定箇所：** LINE Official Account Manager → 応答設定

| 項目 | 設定値 |
|---|---|
| 応答モード | **チャット**（担当者が手動返信するモード）|
| あいさつメッセージ | **オン**（Lステップに設定するため、ここはオフにしてよい）|
| 自動応答メッセージ | **オフ**（Lステップで管理）|
| Webhook | **オン**（Lステップ連携に必要）|

**不在時の自動応答（コピペ用）：**
```
メッセージをありがとうございます。

現在担当者が不在のため、
返信まで24時間以内を目標にしています。

お急ぎの場合は、よくある質問もご覧ください。
→ 〔FAQページURL〕
```

## 3. リッチメニュー設定

**設定箇所：** Lステップ → リッチメニュー管理
（LINE Official Account Managerでも設定可能だが、Lステップ経由の方がセグメント別切り替えができる）

### レイアウト：大（2行×3列 = 6ブロック）

```
┌──────────┬──────────┬──────────┐
│  体験会に  │ 活動の様子 │よくある質問│
│ 申し込む  │  を見る   │（費用など）│
├──────────┼──────────┼──────────┤
│担当者に   │  活動日程  │  入団まで  │
│話しかける │  を確認   │  の流れ   │
└──────────┴──────────┴──────────┘
```

### 各ボタンの設定

| ボタン | アクション種別 | リンク or テキスト |
|---|---|---|
| 体験会に申し込む | URL | Googleフォームのリンク |
| 活動の様子を見る | URL | InstagramのプロフィールURL |
| よくある質問（費用など） | URL | HPのFAQページURL |
| 担当者に話しかける | テキスト送信 | 「担当者に相談したい」（自動でトークが始まる）|
| 活動日程を確認 | URL | HP活動カレンダーページURL |
| 入団までの流れ | URL | HP入団ページURL |

### リッチメニューの画像仕様

- サイズ：2500×1686px（6ブロック・大）
- 各ブロックにアイコン＋テキストで作成
- 推奨ツール：Canva（テンプレートあり）
- 背景色：スカウトグリーン（#2E7D32）を基調に

## 4. Lステップ 連携・初期設定手順

### 連携手順

1. `https://lstep.app/` にアクセスしてアカウント作成
2. 「LINE連携」→ LINE公式アカウントと連携
3. LINE Official Account Manager → Webhook URLをLステップのURLに変更
4. Lステップ管理画面 → 「チャンネル設定」で連携確認

### 基本設定チェックリスト

- [ ] LINE公式アカウントとの連携完了
- [ ] Webhook設定完了
- [ ] あいさつメッセージをLステップで作成（LINE側はオフに）
- [ ] タグの作成（ビーバー・カブ・パパ・ママ・両方・体験済み・入団）
- [ ] リッチメニューの作成と設定

## 5. Lステップ シナリオ設定（詳細）

**設定箇所：** Lステップ → シナリオ → 新規作成

### シナリオ名：「友達追加フロー」

| ステップ | 待機時間 | アクション | 備考 |
|---|---|---|---|
| Step 1 | 即時 | あいさつメッセージ送信（ボタン付き） | 友達追加トリガー |
| Step 2 | ボタンタップ後・即時 | 年齢別動画送信（条件分岐） | タグで分岐 |
| Step 3 | Step 2から72時間後 | パパ/ママ確認メッセージ | 200通カウント対象 |
| Step 4 | Step 3から96時間後 | 2本目の動画送信 | セグメント別 |
| Step 5 | Step 4から168時間後 | 3本目の動画（体験会への誘導） | 全セグメント |

### 条件分岐の設定方法

1. Step 2に「条件分岐」を追加
2. 条件：タグ「ビーバー」を持っているか
   - YES → ビーバー向けの動画を送信
   - NO（＝カブ）→ カブ向けの動画を送信

## 6. キーワード自動応答の設定（Lステップ）

**設定箇所：** Lステップ → 自動応答 → キーワード応答

### 設定一覧

| キーワード | マッチ方式 | 返信メッセージ |
|---|---|---|
| 体験、見学、参加 | 部分一致（OR） | 「ありがとうございます！次回の体験日は〔○月○日〕です。お申し込みはこちら→〔URL〕」 |
| 費用、料金、いくら、お金 | 部分一致（OR） | 「入団金：〔○〕円、月会費：〔○〕円程度です。詳細はこちら→〔URL〕　他にご質問があればお気軽に！」 |
| いつ、次回、日程、活動日 | 部分一致（OR） | 「次回の活動は〔○月○日（○）〕9:00〜12:00、〔○○公園〕です。見学歓迎です！」 |
| こんにちは、はじめまして、こんばんは | 部分一致（OR） | 「ようこそ！何でもお気軽にどうぞ😊　まずはお子さんの学年を教えていただけますか？」 |
| ありがとう | 部分一致 | 「こちらこそありがとうございます！またいつでもご連絡ください。」 |
| 申し込み、申込 | 部分一致 | 「お申し込みはこちらから承ります→〔Googleフォームリンク〕　ご不明な点はいつでも返信してください。」 |

## 7. セグメント別配信の設定手順（毎回）

1. Lステップ → 「配信」→「新規配信」
2. 「配信対象」を「タグで絞り込む」に設定
3. 対象タグを選択（例：`カブ` AND `ママ`）
4. メッセージ内容を入力またはテンプレートから選択
5. 配信日時を設定（8:00〜21:00の範囲で）
6. プレビューを確認
7. 「予約配信」をクリック

## 8. よくある質問（FAQ）ページの構成（HP用）

LINEのリッチメニュー「よくある質問」ボタンのリンク先として使用。

**掲載する質問（推奨10問）：**

```
Q1. どんな活動をしていますか？
A. キャンプ・ロープワーク・野外料理・地図読み・工作など。
   月2回、2〜3時間の活動です。

Q2. 対象年齢は？
A. ビーバー隊：年長〜小学1年生
   カブ隊：小学2〜5年生

Q3. 費用はどれくらいかかりますか？
A. 入団金：〔○〕円（初回のみ）
   月会費：〔○〕円前後
   キャンプ：年1〜2回、1回〔○〕円前後

Q4. 親の参加は必須ですか？
A. 活動中の付き添いは不要です。
   保護者会が月1回程度あります。

Q5. 他の習い事と掛け持ちできますか？
A. できます。活動は月2〜3回のため、
   他の習い事と両立している子が多いです。

Q6. 途中から入団できますか？
A. いつでも入団できます。
   まずは体験会にご参加ください。

Q7. 制服は必要ですか？
A. 入団後に購入いただきます。
   体験中は私服で参加できます。

Q8. 送り迎えはどうすればいいですか？
A. 現地集合・現地解散が基本です。
   場所はLINEで事前にご案内します。

Q9. 子どもが人見知りでも大丈夫ですか？
A. 大丈夫です。
   最初は見ているだけでも構いません。
   少人数なので馴染みやすい環境です。

Q10. 見学だけでもできますか？
A. もちろんです。
   入団を決めなくても参加できます。
   まずはLINEでご連絡ください。
```

## 9. 月次運用チェックリスト

毎月1日に確認する項目：

- [ ] 月の活動日程を確定し、全シナリオ内の日付を更新
- [ ] リッチメニューの「活動日程を確認」リンク先ページを更新
- [ ] キーワード自動応答内の「次回の活動日」を更新
- [ ] 先月の配信通数を確認（200通の残枠を把握）
- [ ] 新規登録者のタグ付けに漏れがないか確認
- [ ] 体験会参加者への「体験済み」タグ付与
- [ ] 入団者への「入団」タグ付与・配信除外設定
