# 大規模イベント → 日常活動への転換戦略

## 核心的な考え方

大規模イベントと日常活動は「同じものの大小」ではなく、**別の価値**として正直に伝える。

| 大規模イベント | 日常活動 |
|---|---|
| 非日常・お祭り感 | 小さな積み重ねの深さ |
| 多人数・大きな達成感 | 少人数・名前で呼ばれる安心感 |
| その日限りの興奮 | 半年後に気づく子どもの変化 |

## 橋渡しフレーミング

> 「今日みたいな大きな舞台に立てる子は、普段の活動で小さな積み重ねをした子たちです」

## アクションタイムライン（イベント後）

| タイミング | アクション |
|---|---|
| 24時間以内 | メールOK対象者へお礼＋次回活動案内を送信 |
| 3〜5日以内 | 全員に体験参加の案内（日時・場所・持ち物） |
| 7日以内 | 返信者に「服装は動きやすいもの・途中帰宅OK」を送る |
| 返信なし | 1回だけ軽いフォロー → LINEの月次配信に切り替え |

## ギャップを防ぐ一言（案内文に必ず入れる）

> 「今日みたいな大きなイベントとは雰囲気が違いますが、少人数だからこそリーダーが○○くんの名前と得意なことをすぐ覚えます」

## 日常活動の言語化

避けるべき言葉 → 代わりに使う言葉：

| 避ける表現 | 代わりに |
|---|---|
| 「月2〜3回の活動です」 | 「半年後に子どもが変わっていることに気づきます」 |
| 「少人数の活動です」 | 「リーダーが○○くんの名前と得意なことを知っています」 |
| 「地道な活動です」 | 「昨日できなかったことが、来月できるようになる」 |
| 「継続が大事です」 | 「続けた子だけが知っている達成感があります」 |

## 活動後SNS・LINE発信テンプレート（3点セット）

毎回の活動後にこれだけ投稿する：

1. 写真1〜2枚（子どもの「真剣な顔」か「達成した瞬間」）
2. 今日やったこと（1行）
3. 子どもの「ひと言」か「変化」（1行）

```
【今日の活動レポート】

🪵 今日は「まきを使った火おこし」に挑戦！

「こんなに難しいと思わなかった」と言っていた○年生が、
30分後には自分でやり遂げました。
できた瞬間の顔、最高でした。

次回は◯月◯日です。
体験参加、随時受付中です👇
```
